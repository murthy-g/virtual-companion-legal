Information We Collect — Personal Information

Face Data and Photos

We collect and process face data and photos for the following purposes: • Human verification photos taken with your device's front camera • Profile photos you choose to upload for avatar generation • Camera-captured images for avatar description inspiration • Gallery images selected for avatar creation prompts • Face data extracted from photos for AI-powered avatar creation, used to: – Verify that you are a real human user (not a bot or fake account) – Ensure age verification compliance (18+ requirement) – Generate AI-powered avatar images using DALL-E 3 – Create personalized avatar descriptions and prompts Storage: Avatar images and metadata, chat conversations, and avatar personality data are stored locally using device encryption. Face data is processed once for verification, then deleted from our servers. Only minimal account data (email, age, preferences) is stored in secure cloud databases. We may share data with: AI service providers (OpenAI) for avatar generation and chat responses (processed securely, not stored by them), AWS cloud services for secure data storage and processing, and legal authorities when required by law or court order.

User Activity Logging

For security, compliance, and service improvement purposes, we collect and store detailed logs of your account activities: • Account Activities: registration, login, profile updates, account deletion, and terms acceptance • IP Address: for security analysis and fraud prevention • User Agent: information about your device and browser for technical support • Activity Status: success/failure status of actions and any error messages • Timestamps: precise timing of all account-related activities

Data Security

We implement comprehensive security measures to protect your personal information, with a focus on local device security: • Local Encryption: all sensitive data is encrypted using AES-256 encryption on your device • Device Security: uses iOS Keychain and Android Keystore for secure key management • End-to-End Encryption: chat messages are encrypted locally before any transmission • Minimal Cloud Storage: only essential account data is stored in secure cloud databases • Secure Transmission: all data transmission uses TLS 1.3 encryption • Regular Security Updates: continuous security assessments and updates • Access Controls: strict authentication and authorization measures However, no method of transmission over the internet or electronic storage is 100% secure. While we strive to protect your information using industry-leading security practices, we cannot guarantee absolute security.
